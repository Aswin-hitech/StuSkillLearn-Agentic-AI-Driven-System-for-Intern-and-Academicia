# SIH Demo Guide

Use the four one-click demo accounts on the login screen. Password for all seeded accounts: `Demo@123`.

## 1. Student — prove readiness intelligence
Login: `student@stuskilllink.demo`

Show in this order:
1. Overview: readiness, LSRW, skill gaps, top matches.
2. Profile & Resume: upload a TXT/PDF/DOCX resume and map skills.
3. Preferences: set domains, work modes, ranked roles and general-pool opt-in.
4. LSRW: complete listening, speaking, reading and writing.
5. Learning: complete a gap recommendation or industry program.
6. Portfolio: show verified badges.
7. Opportunities: open a role and explain the score/gap evidence.
8. Offers: show rank, allocation round, category slot and offer letter.

## 2. Industry — prove transparent allocation
Login: `industry@stuskilllink.demo`

Show:
1. Publish an internship or placement role with structured skills.
2. Open Company-wise Rank Lists.
3. Explain score components + tier + deterministic tie-break order.
4. Allocate seats.
5. Record real company feedback.
6. Show industry-led learning programs.

## 3. Student again — prove automatic reallocation
Open the Student Offers page and reject an `OFFERED` allocation. Then return to Industry → Allocation & Feedback and show the next eligible candidate receiving a later allocation round.

## 4. Academician — prove faculty opportunity extension
Login: `academician@stuskilllink.demo`

Show expertise matching for FDP, research and consultancy opportunities and the curriculum signals derived from live hiring demand.

## 5. Institution — prove the closed loop
Login: `institution@stuskilllink.demo`

Show:
- student readiness
- average LSRW
- current skill supply
- curriculum gap evidence
- curriculum actions
- academician opportunities

## 6. Agent activity — explain architecture
Open Agent Activity from any workspace. The six specialized agents expose their responsibility and outputs. Emphasize that AI assists interpretation while deterministic services make ranking/allocation decisions.

## Judge-friendly one-line architecture
**Skill gap → LSRW/readiness → learning → verified portfolio → preference-aware ranking → explainable allocation/reallocation → industry feedback → placement continuity → curriculum insight.**
